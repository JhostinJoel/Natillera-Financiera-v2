# Versionamiento

Comandos locales:

```powershell
git add .
git commit -m "feat: sistema financiero de natillera"
git remote add origin https://github.com/JhostinJoel/Natillera-Financiera.git
git branch -M main
git push -u origin main
```

`.gitignore` excluye `.env`, `.venv`, cachés y archivos compilados.
